Set up the group directory on Blogger

From an empty Google Sheet to a live directory, in about 40 minutes. Tick each task as you finish it; your ticks are saved in this browser. Wherever you see YOUR-…, use your own value.

You'll need:
  1. A Google account (for the Sheet and Apps Script).
  2. A free GitHub account.
  3. A Blogger blog.

1

GitHub

Hosts the design, the scripts and the fast copy of the group list, for free.

1.1 · Create the repository

github.com → New repository
  1. Sign in at github.com → + → New repository.
  2. Pick a name (this guide calls it YOUR-REPO), choose Public (GitHub Pages is free for public repositories) → Create repository.
  3. Click uploading an existing file and drag in every file and folder from this project, including the .github folder → Commit changes.
⚠️

Don't upload your filled-in blogger/theme.xml, your page texts or personal notes. The included .gitignore keeps them out when you use Git; when you drag files in by hand, leave them out yourself.

1.2 · Turn on GitHub Pages

Repository → Settings → Pages
  1. Settings → Pages → Build and deployment → Source: GitHub Actions.
  2. Your files will be served from https://YOUR-GITHUB-USER.github.io/YOUR-REPO/.
2

Google Sheet · Apps Script

The database and the web app that takes submissions.

2.1 · Make the sheet

sheets.google.com
  1. Create a new Google Sheet. Rename the first tab to Group Links (or change CONFIG.SHEET in Code.gs to match).
  2. Click cell A1, click Copy below and paste. It fills the 12 column headings.
row 1

2.2 · Add the script

Sheet → Extensions → Apps Script
  1. In the sheet: Extensions → Apps Script.
  2. Replace everything in Code.gs with apps-script/Code.gs from this project.
  3. Find const GH_REPO and set it to 'YOUR-GITHUB-USER/YOUR-REPO'. Save (Ctrl + S).
  4. Optional: adjust CONFIG, CATEGORIES and BLOCKED at the top.

2.3 · Deploy it as a web app

Apps Script → Deploy → New deployment
  1. Deploy → New deployment → gear icon → Web app.
  2. Execute as: Me. Who has access: Anyone → Deploy → allow the permissions.
  3. Copy the Web app URL (it ends in /exec). This guide calls it YOUR-APPS-SCRIPT-URL.
⚠️

Later updates: always use Deploy → Manage deployments → ✏️ → New version. A new deployment gets a new URL and the site would stop getting groups.

2.4 · Create the shared secret

Apps Script → Run
  1. In the function menu next to ▷ Run, pick setupGitHubHelper → Run.
  2. The log shows a long code. Copy it; you'll paste it into GitHub in step 3.1 as ENRICH_TOKEN.

2.5 · Let the script start the GitHub job

github.com → Settings → Developer settings
  1. GitHub → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → YOUR-REPO. Permissions: Actions → Read and write. Generate and copy it.
  3. Apps Script → Project Settings (gear) → Script properties → Add script property: name GITHUB_TOKEN, value = the token → Save.
🔒

Keep tokens only in Script properties and GitHub secrets. Never paste them into a file, a post or the theme.

2.6 · Install the timers

Apps Script → Run
  1. Pick setup → Run.
  2. It installs: start the GitHub job every 15 minutes, retry unread links every 6 hours, re-check live links daily, and (if enabled) a daily random bump.
3

Connect GitHub to the script

So the job can read the list and save group names and photos.

3.1 · Add two secrets

Repository → Settings → Secrets and variables → Actions
  1. New repository secret: name APPS_SCRIPT_URL, value YOUR-APPS-SCRIPT-URL.
  2. New repository secret: name ENRICH_TOKEN, value = the code from step 2.4.

3.2 · Run the job once

Repository → Actions
  1. Actions → if asked, enable workflows → Sync groups + publish → Run workflow.
  2. After about 2 minutes, open https://YOUR-GITHUB-USER.github.io/YOUR-REPO/data/groups.json. You should see a list (empty brackets are fine before the first submission).
4

Blogger

Put the theme in place and add the pages.

4.1 · Fill in the theme

blogger/theme.template.xml
  1. Copy blogger/theme.template.xml to blogger/theme.xml (this copy stays on your computer).
  2. Open it in a text editor and use Find & Replace for each placeholder below.
  3. Search for EDIT to change the menu, FAQ, footer links and texts. Keep the footer credit Designed & Developed by Nivesh Sahayak and its link as they are.
PlaceholderReplace withNeeded?
YOUR-GITHUB-USER.github.io/YOUR-REPOYour GitHub Pages addressYes
YOUR-APPS-SCRIPT-IDThe id part of your web app URLYes
www.your-domain.comYour blog's addressYes
ca-pub-0000000000000000Your AdSense publisher idIf you use AdSense
G-XXXXXXXXXXYour Google Analytics idIf you use Analytics
YOUR-YANDEX-CODEYour Yandex verification code, or delete that lineOptional
YOUR-PAGE, YOUR-NAMEYour social profilesOptional

4.2 · Back up, then upload

Blogger → Theme
  1. Blogger → Theme → ⌄ next to Customize → Backup → Download. Keep this file.
  2. Same menu → Restore → upload your filled-in blogger/theme.xml.
  3. Always use Restore, not Edit HTML. To undo, restore your backup.
💡

Try it on a spare test blog first if your blog already has visitors.

4.3 · Promo card and favicon

Blogger → Layout
  1. Layout → Promo card between groups → ✏️ → paste any HTML (a banner, a link, or an AdSense <ins> unit) → Save. It appears after every few groups and articles.
  2. Layout → Favicon → upload your own square icon (for example assets/brand/favicon-512.png after you replace it).

4.4 · Add the pages

Blogger → Pages → New page → HTML view
  1. Create the pages the menu links to (submit, contact, how to join, how to share, privacy, disclaimer…), with your own text.
  2. Where a page needs a tool, paste the matching snippet in HTML view. The theme fills it in.

5

Check and run it

Use a private window so you don't see cached copies.

5.1 · Test it

your blog
  1. Submit a test group. Its card appears at once; its name and photo fill in within about 15 minutes.
  2. Check the header logo, dark and light mode, search, a category, Share and the report flag.
  3. Open a blog post and each page you made.

5.2 · Everyday running

reference
  1. Hide a listing: set its status to hidden in the sheet. Set it back to live to show it.
  2. Block new words: edit BLOCKED in Code.gs → Deploy a new version → run remoderate.
  3. Change the design: edit assets/syg.css or assets/syg.js on GitHub; it's live in about 2 minutes.
  4. Change the theme: edit your theme.xml → Blogger → Restore. Then run scripts/make-theme-template.ps1 if you share your copy of the project.
  5. List not updating? GitHub → Actions → open the latest run. If workflows are disabled, enable them.
